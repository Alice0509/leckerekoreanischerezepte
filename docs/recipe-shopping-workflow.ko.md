# 레시피에서 재료 구매로 연결

레시피의 재료 목록 바로 아래에 접힌 구매 안내를 표시한다. 기존에 제품 예시가
준비된 재료 중 해당 레시피에 실제 연결된 재료만 모은다. 제품 예시가 없는
재료나 연결되지 않은 양념을 임의로 추가하지 않는다.

- EN: Find ingredients for this recipe
- DE: Zutaten für dieses Rezept finden

처음에는 요약 한 줄만 보인다. 펼치면 재료 설명, 정확한 제품 예시, 매장 이름,
구매 지역과 짧은 제품 버튼을 볼 수 있다. 영어 사이트의 미국 매장은 United
States로 표시한다. 미국 링크가 없는 재료도 해당 재료의 현지 구매 안내로 이동할
수 있다. 독일 사이트는 기존 독일 매장을 사용한다.

전체 재료 목록과 분량은 기존 목록이 기준이다. 제품 포장 용량을 레시피 사용량과
동일하게 표시하지 않는다. 이 영역은 기존 구매 후보를 연결하며 새 상품에 대한
개인 사용 후기를 만들어내지 않는다. 제품 변형 설명은 재료 안내에서 확인한다.

## 수익화에 연결하는 순서

1. Asiafoodland·REWE·iHerb의 실제 승인 결과를 확인한다. 신청과 승인은 구분한다.
2. 승인된 업체의 정확한 제품용 링크를 발급받는다. 제품명, 포장 용량, 배송
   지역과 레시피 적합성을 확인한다.
3. 기존 제휴 레지스트리에 해당 일반 상품 주소와 승인된 추적 주소를 연결한다.
   새 업체의 제품은 먼저 국가별 제품 목록에 별도 검토하여 추가한다.
4. 미리보기에서 광고 표시와 실제 제품 목적지를 검토하고 활성화하여 배포한다.
   이번 변경 자체는 제휴 링크를 활성화하지 않는다.
5. Search Console의 페이지별 유입, 동의 기반 GA4의 외부 링크 클릭 상태,
   제휴 대시보드의 확정 수수료를 따로 확인한다. 클릭을 수익으로 계산하지 않는다.

승인되면 연결 경로는 레시피 → 해당 제품, 레시피 → 재료 안내 → 해당 제품,
Kitchen Picks → 승인된 제품으로 이어진다. 실제 클릭·판매 데이터가 쌓인 뒤
반응이 있는 재료부터 보완한다. 이 변경만으로 매출 증가를 보장하지 않는다.

## 검토

영어·독일어의 비빔 소스와 일본 카레 레시피에서 구매 안내를 펼쳐 확인한다.
비빔 소스에는 카레 제품이 나타나지 않아야 한다. 구매 안내가 없는 레시피에는
빈 영역이 생기지 않아야 한다. 재료 체크박스와 기존 분량, 조리 단계는 유지한다.
모바일에서 펼치기 전 길이, 상호명 줄바꿈과 짧은 버튼을 확인한 뒤 merge한다.
Sanity Studio 배포나 Publish는 필요 없다.
