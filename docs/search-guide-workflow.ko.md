독일 지역 안내는 독일어 고추장 문서에만 남습니다.

## 실행과 공개

작업 ZIP의 `apply-and-open-pr.sh`는 별도 Git 작업 폴더를 만들고 테스트 후 검토용 PR을 준비합니다.
`prepare-search-drafts.sh`는 그 폴더의 Sanity CLI를 통해 로그인한 사용자 권한으로 초안 3개를 만듭니다.
자동 공개하지 않습니다. Studio 재배포도 필요 없습니다.

1. https://hansik-young.sanity.studio/ 에서 소보로빵, 단팥빵, 고추장 문서를 여세요.
2. 소보로빵·단팥빵은 English 소개와 SEO, 고추장은 Deutsch 소개와 SEO를 확인하세요.
3. 사진·다른 언어·기존 재료와 조리 단계가 정상인지 확인한 후, 원하는 문서만 Publish하세요.
4. 기존 공개용 웹훅이 연결되어 있으면 Publish 후 웹사이트 빌드가 진행됩니다. 빌드 완료 후 해당 언어 페이지를 확인하세요.

PR 병합만으로 Sanity 내용이 공개되지는 않습니다. 초안 생성은 공개 문서를 수정하지 않습니다.
초안 단계에서도 빌드를 실행하는 웹훅이 별도로 있다면 그 설정의 영향을 받을 수 있습니다.

## 기존 편집 보호

다른 초안이나 준비 당시와 다른 소개가 있으면 전체 작업을 중단합니다. 기존 초안을 덮어쓰지 않습니다.
동일한 준비 초안 또는 이미 공개된 내용은 건너뛰므로 재실행이 가능합니다.
문서를 다시 읽어 수정 여부를 확인한 후, create-only 트랜잭션 한 번으로 필요한 초안을 만듭니다.
마지막 확인 직후 다른 사용자가 공개 문서를 수정하는 상황까지 잠글 수는 없으므로 공개 전 검토가 필요합니다.

## 성과 확인

공개 날짜를 기록하고 이후 같은 길이의 기간으로 페이지별 Google 검색 노출·클릭·검색어를 비교하세요.
GA4는 동의한 방문자의 행동을 보완해서 봅니다. 페이지별 노출을 합산해 전체 사이트 노출로 해석하지 않습니다.
검색 순위나 수익 상승을 보장하는 변경은 아닙니다.
