# 레시피 검색 정보 관리

레시피 페이지에서 사용하는 검색 정보는 Sanity에 게시된 실제 내용에서 만듭니다.

- `preparationTime`은 현재 한 가지 조리 시간만 기록합니다. 검색 정보에는 `totalTime`으로 전달하며, 별도로 확인하지 않은 준비 시간이나 가열 시간을 더하지 않습니다. 비빔 소스의 5분은 소스 자체를 만드는 시간입니다.
- 최초 게시일이 확인되는 레시피에만 `datePublished`를 넣고 페이지 상단에도 게시일을 표시합니다. 기존 Contentful 콘텐츠를 Sanity로 옮긴 날짜는 최초 게시일로 사용하지 않습니다.
- 수정일은 최초 게시일과 별도로 전달합니다. 본문을 수정해도 최초 게시일은 바뀌지 않습니다.
- 조리 단계는 페이지에 보이는 순서대로 전달하고 각 단계에 `#step-1`, `#step-2`처럼 직접 연결되는 주소를 붙입니다. 이전 방식의 조리 설명은 `#instructions`에 연결합니다.
- 별도의 단계 제목이 없으므로 검색 정보에서 `Step 1` 같은 숫자 제목을 만들지 않습니다. 실제 조리 설명은 `text`로 전달합니다.
- 식재료 분량, 사진, 레시피 주소와 Sanity 문서는 이 변경으로 수정하지 않습니다.

새 채팅 레시피를 일괄 게시하면 최초 게시일이 자동으로 기록됩니다. 직접 작성한 새 레시피는 실제 최초 게시일을 입력할 수 있습니다. 오래된 레시피의 날짜를 모르면 비워 두세요.

Google 공식 레시피 가이드:
https://developers.google.com/search/docs/appearance/structured-data/recipe

Merge와 Vercel 배포가 끝나면 Google 리치 결과 테스트에서 공개 레시피 주소를 검사할 수 있습니다:
https://search.google.com/test/rich-results

이 변경은 검색 정보의 정확성을 높이는 작업이며, 검색 순위나 리치 결과 표시를 보장하지 않습니다. 영상·영양·평점 등 별도 정보의 완전성은 이번 변경의 검증 범위에 포함하지 않습니다.
