# 고추장·고춧가루 선택 안내 보완

고추장 재료 안내를 구체적인 영어·독일어 profile로 구성하고 고춧가루
페이지와 서로 연결한다. 사진 촬영, CMS 문서 수정, Studio 배포 없이
기존 재료 설명 페이지에서 구매 전 차이를 확인할 수 있다.

- 고추장 페이스트와 완성 소스는 제품명·원재료로 구분한다.
- 포장 색이나 용기만으로 제품 종류와 맵기를 판단하지 않는다.
- 고추장과 고춧가루를 같은 양으로 대체하지 않는다. 실제 비빔 소스
  레시피는 두 재료를 별도로 사용한다.
- 쌀이 들어간 고추장이라고 자동으로 밀 없는 제품이라고 안내하지 않는다.
  구체적인 제품의 원재료와 알레르기 표시를 확인한다.
- 새 비교 FAQ는 처음에 접힌 상태다. 답변의 재료 링크로 반대편 안내에
  이동할 수 있다. 실제 비빔 소스 레시피 링크도 같은 FAQ에 연결한다.
  기존 구매·레시피 카드와 일반 상품 링크는 유지한다.
- 영어판은 글로벌 대상이고, 독일어판 구매 안내는 독일 기준이다.
- 새 비교 답변과 FAQ 구조화 데이터는 같은 문자열을 사용한다.

## 수익화와의 관계

제품 선택에 필요한 내용을 보완하는 작업이며 새로운 제휴 링크나
수수료를 활성화하는 작업은 아니다. 실제 검색 유입, 구매 클릭, 확정
수수료가 늘어나는지는 이후 데이터로 확인해야 한다. 업체 승인 후
발급된 정확한 상품용 제휴 링크는 별도 검토로 연결한다.

## 확인한 자료

2026-10-08 제조사 공식 설명을 확인했다. 모든 제품이 같은 원재료로
만들어진다는 뜻이 아니며, 실제 구매 제품의 표시가 기준이다.

- [Sempio Classic 고추장](https://en.sempio.com/product/jangpaste/view/622):
  진한 페이스트, 매운맛·단맛·감칠맛, 밀·대두 표시.
- [O’food 고추장 페이스트](https://ofoodeurope.com/product/gochujang-paste-170g-500g/):
  페이스트 원재료와 별도 제품 표시.
- [O’food 고추장 소스](https://ofoodeurope.com/de/product/gochujang-sauce-de/):
  완성 소스의 원재료와 당·소금 구성이 페이스트와 다름.
- 비빔 소스의 두 재료 사용 및 분량은 사용자가 제공한 실제 레시피와
  공개된 `chat-recipe-bibim-noodle-sauce`를 기준으로 한다.

## 검증과 적용

실제 페이지 렌더링 테스트에서 EN/DE 답변과 FAQ 데이터 일치,
접힌 상태 및 상호 링크를 확인한다. 기존 테스트의 과거 펼친 레이아웃
검사를 현재 접힌 설명 레이아웃에 맞게 갱신한다. 전체 빌드 후 실제
재료·레시피 경로, 기존 구매 링크 및 지역 구분을 확인한다.

PR Preview에서 두 언어의 고추장·고춧가루 FAQ를 열고 링크를 확인한 뒤
merge한다. Sanity Studio 배포나 Publish는 필요 없다.
