# 한식 시작 도구 안내

추가 사진 촬영 없이 읽을 수 있는 영어·독일어 안내 페이지:
`/korean-kitchen-tools`. 기존 기본 양념 안내(`/korean-pantry`)에서 연결합니다.

- 먼저 가진 도구를 확인하도록 안내합니다. 고가 제품이나 새 장비 구매를
  필수 조건으로 만들지 않습니다.
- 조리·손질·계량 기본 도구는 바로 보이고, 밥솥·김밥발·블렌더·보관통은
  기본적으로 접힌 안내로 제공합니다.
- 기존 계량 설명을 그대로 사용하며, 밥숟가락과 15 ml 계량스푼을 동일하게
  취급하지 않습니다.
- 쌀밥·비빔 소스·김치전은 공개된 레시피 ID로 연결합니다. 레시피가 사라지면
  빌드 단계에서 확인하도록 합니다. CMS 문서나 레시피 내용은 수정하지 않습니다.
- 영어판은 글로벌 대상입니다. 독일 매장, 독일 구매 조건을 영어판에 넣지 않습니다.
- 두 도메인의 canonical·hreflang 및 사이트맵에 새 경로를 추가합니다.

## 수익화 연결

현재 제품 버튼이나 제휴 링크는 추가하지 않습니다. 신청 대기 또는 자격 확인
중인 업체를 승인된 파트너로 표시하지 않으며, 작성자가 제품을 직접 사용했다는
후기를 만들지 않습니다.

실제로 쓰는 도구를 확인한 뒤 선택 기준과 사용 예시를 보완합니다. 업체 승인을
받고 정확한 제품용 제휴 링크가 발급되면, 기존 PurchaseLink와 제휴 고지 구조를
사용하는 별도 PR로 적용합니다. 검토 후보는 독일 Reishunger 일반 제휴와
Amazon PartnerNet입니다. 가입 가능 여부와 신청 조건은 별도로 확인합니다.

추가 촬영이 어려운 기간에는 실제 조리 팁을 짧게 받아 설명을 보완할 수 있습니다.
사진이 있을 때만 실제 촬영 사진으로 추가하고, 생성 이미지를 실제 조리 증거나
제품 사용 후기처럼 소개하지 않습니다.

## 확인

변경 파일의 Prettier·ESLint, 전체 프로덕션 빌드 후 EN/DE 경로·내부 링크·
canonical·hreflang·사이트맵을 확인합니다. PR 미리보기에서 모바일 글줄과
접기/펼치기를 확인한 뒤 병합합니다. Studio 배포나 Publish는 필요 없습니다.
