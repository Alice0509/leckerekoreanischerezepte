# 레시피 발행과 성장 루틴

## 이번 변경

- 홈 상단은 최신 레시피 2개와 이번 주 추천 1개, 총 3장을 보여줍니다. 새 글은 날짜순이며, 추천은 검토한 기존 레시피 8개에서 돌아갑니다. 같은 레시피를 두 칸에 중복 표시하지 않습니다.
- 추천은 독일 시간으로 월요일 0시에 바뀝니다. 브라우저에서 자동 갱신되므로 추천을 바꾸기 위한 주간 빌드는 필요하지 않습니다. 오래 열어 둔 페이지는 최대 1분 안에 갱신됩니다. EN/DE에서 같은 요리를 추천합니다.
- 첫 공개 날짜를 아는 레시피가 부족하면 기존 요리를 ‘From my kitchen / Aus meiner Küche’로 표시해 빈칸을 채웁니다. 이전 날짜를 게시일로 추정하지 않습니다.
- 첫 공개 후 30일 동안 홈 카드에 NEW / NEU가 붙습니다. 내용 수정일과 Sanity 이전 날짜는 기준으로 사용하지 않습니다. 표시는 브라우저에서 만료되어 매일 새 빌드를 할 필요가 없습니다.
- 채팅 레시피 도구의 일괄 발행은 첫 공개 날짜를 자동 저장합니다. 일반 편집기로 만든 새 레시피는 ‘검색·주소 → 첫 공개 날짜’에 실제 공개 시각을 입력합니다. 기존 레시피의 수정 때는 변경하지 않습니다.
- 이미 일괄 발행한 채팅 레시피는 공개 문서가 만들어진 시각을 사용합니다. 이전한 52개 레시피에 최근 날짜를 부여하지 않습니다.
- 비빔 소스와 국수 삶기 안내가 서로의 관련 레시피에 먼저 나옵니다. 실제 존재하는 번역별 주소를 사용합니다.

## 적용 순서

1. 새 ZIP의 `apply-and-open-pr.sh`로 검토용 PR을 만들고 검토 후 merge합니다. Vercel Production이 Ready인지 확인합니다.
2. 홈에서 최신 2개와 추천 1개를 확인하고, 카레 페이지의 Golden Curry 안내 링크를 눌러 봅니다.
3. 각 레시피 아래 ‘Share this recipe / Dieses Rezept teilen’을 열면 해당 언어의 정확한 링크와 짧은 소개를 복사하거나 사진으로 만든 1080×1350 PNG를 다운로드할 수 있습니다. Pinterest용 1000×1500 PNG와 제목·설명·링크를 각각 준비하는 기능도 있습니다. 자세한 순서는 `docs/pinterest-recipe-sharing.ko.md`를 참고합니다. 계정 연결이나 유료 이미지 서비스는 사용하지 않습니다.
4. ZIP에는 현재 비빔 소스 사진을 활용한 EN/DE 공유 이미지와 `share-captions.txt`를 넣었습니다. 실제 사진 전체를 유지하며, 소스 사진을 완성 비빔면 사진으로 바꾸지 않습니다.
5. 지난 단계에서 아직 공개하지 않은 파스타 설명을 반영하려면 ZIP의 `update-noodle-pasta.sh --dry-run`, 이어서 `--apply`를 실행합니다. 초안이나 준비 이후 수정이 있으면 덮어쓰지 않고 중단합니다. Studio에서 해당 레시피를 동시에 편집하지 마세요.

이번 웹 기능에는 별도 Studio 배포가 필요하지 않습니다. 채팅 발행의 첫 공개 날짜 자동 기록은 PR #96의 Studio 버전을 사용하는 기능이므로 그 배포는 완료해 두세요.

## 매주 한 레시피

1. 직접 만든 음식의 사진과 메모를 채팅에 보냅니다. 맛, 실패하기 쉬운 점, 대체 재료 한 가지도 함께 적으면 좋습니다.
2. EN/DE 소개·재료·단계를 정리하고 목록으로 실제 식재료를 연결합니다. 모호한 분량과 시간은 확인한 내용만 적습니다.
3. Studio에서 초안을 가져오고 사진과 조리 내용을 확인한 후 한 번에 발행합니다.
4. 홈페이지 새 글 표시와 두 언어 링크를 확인합니다.
5. 레시피 페이지의 공유 기능으로 사진 카드와 소개를 준비합니다. 소개는 ‘어떤 문제를 해결하는 요리인지’ 한 문장과 해당 언어의 레시피 링크로 시작합니다. 예: 아시아마트에 가지 못한 날, 집에 있는 얇은 파스타로 만드는 비빔면.

## 한 달에 한 번 확인

매달 4일 저녁(독일 시간), Search Console 보고서 내보내기 안내를 받도록 설정했습니다. 첫 안내는 2026년 11월 4일입니다. 이 알림은 보고서 수집 안내이며 Google 계정을 자동으로 조회하지 않습니다.

Search Console에서 EN/DE 각각 최근 28일의 검색 노출·클릭·검색어를 이전 28일과 비교합니다. 비교한 페이지·검색어·국가 보고서를 내려받아 채팅에 올리면 다음 콘텐츠와 보완 페이지를 함께 고릅니다. 노출은 있는데 클릭이 적은 페이지, 방문자가 실제로 찾는 질문을 메모해 다음 글이나 보완 작업을 정합니다. GA4는 쿠키 동의한 방문자의 행동을 보는 자료로 사용하며, 전체 방문자 수로 해석하지 않습니다.

처음에는 새 레시피 하나와 기존 글 보완 하나를 꾸준히 쌓는 것을 목표로 합니다. 짧은 기간의 검색 변화로 성공 여부를 판단하거나 수익을 예상하지 않습니다.

## 다음에 키울 콘텐츠

‘일반 슈퍼마켓 재료로 한국 음식 만들기’를 작은 시리즈로 묶습니다. 이번 얇은 파스타 대안처럼 직접 사용해 본 재료, 맛·식감 차이, 원래 재료가 더 좋은 경우를 함께 설명합니다. EN은 세계 어디서든 이해할 수 있는 재료 종류 중심으로, DE는 확인한 현지 제품 정보를 추가할 수 있습니다. 실제 제품·파트너를 확인한 뒤 상품 링크를 붙입니다.

이번 파스타는 브랜드가 확인되지 않아 특정 브랜드나 상품 링크를 지정하지 않았습니다. ‘No. 1’은 작성자가 쓰는 포장 표기이며, 모든 제조사의 공통 규격이나 모든 스파게티의 3–5분 조리 시간을 뜻하지 않습니다.
