# 쌈장: 첫 조리 경험을 모으는 작은 실험

## 이번 변경

- 기존 쌈장 레시피의 재료·분량·조리법·사진·주소·SEO 설정은 유지합니다.
- 조리법 뒤에 영어·독일어 활용 안내를 넣습니다. 자세한 설명은 기본적으로 접혀 있습니다.
- 작은 양을 음식과 함께 맛보기, 익힌 고기와 상추로 쌈 먹기, 된장·고추장·완제품 쌈장의 차이를 설명합니다.
- 된장·고추장의 기존 재료 페이지를 연결합니다.
- 쌈장의 기존 Disqus 질문을 구체적으로 바꿉니다. 어떤 음식과 먹었는지, 무엇을 조절했는지, 잘 안 된 점도 받습니다. 사진은 요구하지 않습니다.
- 새로운 회원가입·평점·후기 데이터베이스·추적·제휴 링크는 추가하지 않습니다. 기존 Disqus 설정이 없으면 댓글 영역은 표시되지 않습니다. Disqus의 실제 작성 조건은 기존 서비스 설정을 따릅니다.

Sanity 문서는 수정하지 않으므로 Studio 배포나 Publish는 필요 없습니다.

## 검토

Vercel 미리보기에서 아래 주소를 엽니다. 영어 기본 미리보기에서는 독일어 확인용으로 `/de/`를 붙입니다.

- 영어: `/recipes/ssamjang-korean-bbq-dipping-sauce`
- 독일어: `/de/recipes/ssamjang-korean-bbq-dipping-sauce`

모바일에서 조리법 아래 짧은 안내와 접힌 설명이 나오는지, 두 재료 링크가 해당 언어로 열리는지 확인합니다. Disqus 환경 변수가 있는 미리보기라면 맨 아래 후기 질문과 버튼을 확인합니다. 클릭하기 전에는 Disqus를 불러오지 않습니다. 게시 테스트가 필요해도 가짜 후기를 남기지 않습니다.

## 먼저 확인할 것

사용자 본인이 가장 중요하게 생각하는 쌈장의 맛 포인트를 다음 대화에서 보완합니다. 매운 정도·대체 비율·보관 기간을 새로 단정하지 않습니다. 이번 활용 아이디어를 실제로 즐기는 개인 경험인 것처럼 표현하지 않습니다.

첫 목표는 실제 조리 경험 10건을 통해 어려움을 배우는 것입니다. 기간 내 달성이나 수익 증가는 보장하지 않습니다. 누군가의 클릭·단계 체크를 실제 조리 성공으로 집계하지 않습니다.

- 레시피 방문은 있는데 후기가 없다면 독자가 실제로 만들었는지 알 수 없습니다.
- 질문이 반복되면 설명을 보완합니다.
- 후기를 다른 곳에 인용하려면 작성자의 동의와 공개 이름을 확인합니다. 지인이라면 관계를 숨기지 않습니다.
- 불편하거나 맛이 맞지 않았다는 의견도 받아들입니다. 광고가 노출되는 페이지의 댓글은 계속 관리해야 합니다.

GA4에는 분석 동의한 방문만 현재 방식으로 반영됩니다. 후기 수·사이트 방문·제휴 클릭·확정 수수료는 각각 별도로 봅니다. 반응이 확인되면 초고추장과 미역국에 맞춘 질문과 활용 안내를 다음 변경에서 준비합니다.
