# 홈 화면과 레시피 카드 정리

홈 소개를 짧게 줄이고 따뜻한 크림색과 짙은 초록색으로 정리합니다. 음식 사진이 먼저 눈에 들어오도록 소개와 탐색 버튼을 배치하고, Joan 소개로 연결합니다. 영어 소개는 글로벌 독자를 대상으로, 독일어 소개는 독일에서 구하는 재료와 대체 재료에 대한 안내를 유지합니다.

최근 레시피 2개와 주간 추천 1개, 최초 게시일 기준 30일 NEW/NEU 표시, 베를린 주간 추천 순환은 그대로 동작합니다. 사진은 기존 CMS 자료를 사용합니다. 카드에는 분류와 레시피 이동 안내가 있고, 홈 추천 카드에만 기존 설명 일부를 보여줍니다. 긴 제목은 잘리지 않습니다.

모바일에서 3개 추천을 세로로 표시해 숨겨진 가로 스크롤을 찾지 않아도 됩니다. 검색창과 분류는 충분한 너비로 배치합니다. 검색 시 선택한 분류가 함께 적용되고, 검색 결과 수를 표시합니다.

시스템의 어두운 테마에서도 이 영역은 같은 밝은 색을 유지합니다. 기존 사이트의 밝은 배경과 일부 카드만 검게 바뀌던 차이를 정리합니다. 키보드 포커스와 버튼 대비를 개선합니다. 별도 폰트 다운로드나 새 추적·유료 서비스는 추가하지 않습니다.

공통 카드와 Home CSS를 사용하는 분류 페이지, 기존 페이지별 목록, 기본 식재료 안내의 카드에도 디자인이 적용됩니다. 글 내용이나 Sanity 문서를 바꾸지 않으므로 Studio 재배포 및 Publish는 필요 없습니다.

## PR 미리보기에서 확인

1. 영어·독일어 홈에서 소개, 3개 사진과 제목, NEW/NEU 및 주간 추천을 확인합니다.
2. 좁은 모바일 화면에서 가로 넘침 없이 카드 3개가 보이는지 확인합니다.
3. 검색과 분류를 함께 선택하고, 결과가 두 조건을 만족하는지 확인합니다.
4. 카드, 분류, Joan 소개 링크를 확인합니다.
5. 분류 페이지 및 기본 식재료 안내의 카드도 확인합니다.
6. 시스템 테마를 바꿔도 글자와 버튼이 읽히는지 확인합니다.

자동 검사는 실제 브라우저에서의 시각 검사를 대신하지 않습니다. 이 환경의 브라우저는 로컬 미리보기에 연결되지 않아 최종 화면 검사는 Vercel PR 미리보기에서 진행해야 합니다. 방문자 증가나 수익 효과는 이 수정만으로 보장되지 않습니다.
