# 한국식 돈까스와 한 끼 구성 연결

기존 영어·독일어 돈까스 레시피, 사진과 재료 설명을 활용합니다. 추가 촬영은 필요 없습니다.

- 돈까스 페이지에 짧은 한 끼 구성 소개를 표시합니다.
- 고기, 빵가루, 곁들임 설명은 처음에 접혀 있습니다.
- 빵가루 설명 페이지에 있는 Samlip 제품 사진을 연결합니다. 현재 판매처나 재고를 보장하는 안내는 아닙니다.
- 이미 게시된 돈까스 소스와 밥 짓기 레시피를 추천에서 먼저 보여줍니다. 소스 페이지에서도 돈까스로 돌아갈 수 있습니다.
- 연결은 게시 레시피 ID를 기준으로 현재 언어의 실제 주소를 사용합니다. 게시 목록에 없는 문서는 추천에 추가하지 않습니다.
- 돈까스·소스의 재료, 분량, 조리 단계, 사진, 시간, 게시 날짜와 SEO 필드는 수정하지 않습니다.
- 이 작업은 새 제휴 링크를 추가하거나 활성화하지 않습니다. 광고주 승인과 발급 링크 확인 후 별도로 진행합니다.

## PR 미리보기 확인

1. 영어·독일어 `/recipes/tonkatsu-korean-style`을 모바일로 엽니다.
2. 한 끼 구성 소개가 보이고 상세 질문은 접혀 있는지 확인합니다.
3. 빵가루 링크에서 기존 제품 사진을 확인합니다.
4. 소스와 밥 짓기 링크가 현재 언어의 레시피로 이동하는지 확인합니다.
5. 소스 페이지 추천에서 돈까스로 돌아갑니다.
6. 기존 돈까스 조리 단계 다섯 개와 육개장 안내가 정상인지 확인합니다.

Sanity Studio 배포나 Publish는 필요 없습니다. 검토한 사이트 PR을 merge하면 Vercel 배포에 반영됩니다.

## 운영

검색 유입은 Search Console, 구매처 클릭은 동의 기반 GA4, 실제 주문·수수료는 승인된 제휴 플랫폼에서 확인합니다. 서로 다른 수집 범위의 숫자를 합쳐 전체 방문자 수나 수익으로 해석하지 않습니다.

새 레시피도 계속 추가하되, 직접 사진이나 영상을 촬영하는 것을 매번 필수 작업으로 만들지 않습니다. 이번처럼 기존 레시피·사진·제품 설명을 연결하는 개선을 병행합니다.
