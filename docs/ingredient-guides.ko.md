# 재료 설명 연결과 제품 사진

## 레시피의 재료 목록

설명이 준비된 재료 이름은 식재료 설명 페이지로 연결됩니다. 재료 이름을
클릭하면 설명을 열고, 체크박스 또는 분량을 클릭하면 준비 여부만 체크합니다.
설명과 실제 사진이 없는 자리표시자 재료에는 빈 설명 페이지 링크를 만들지 않습니다.
재료 페이지의 관련 레시피 목록으로 다시 돌아올 수 있습니다.

## Golden Curry 제품 사진 추가

이미 등록된 `ingredient-sb-golden-curry-roux`에 사진을 추가합니다.
새 재료를 만들거나 기존 레시피의 재료 연결을 바꿀 필요가 없습니다.

Studio 폴더에서 아래 명령을 실행합니다. 사진 파일은 제공된 적용 패키지의
`golden-curry-packages.jpg`이며 사용자가 보낸 원본 JPG입니다.

```bash
npx --no-install sanity exec scripts/addGoldenCurryPhoto.mjs --with-user-token -- --image "$HOME/Downloads/hansik-ingredient-growth-ready/golden-curry-packages.jpg"
```

Sanity CLI에 로그인된 계정을 사용합니다. 토큰을 채팅에 붙여넣을 필요는 없습니다.
사진의 해시와 프로젝트·데이터셋을 확인합니다. 기존 초안이 있으면 편집 내용을
덮어쓰지 않고 중단합니다. 사진이 이미 게시되어 있으면 추가 작업을 하지 않습니다.

사진 업로드 후 식재료 초안만 만듭니다. 이름·주소·소개·레시피 연결은 유지됩니다.
Studio의 식재료 사전에서 Golden Curry 사진을 확인한 후 Publish합니다.
이 스크립트 자체는 공개 문서를 수정하거나 게시하지 않습니다.
사진 업로드 도중 문서가 바뀌면 초안 생성을 중단하며, 업로드된 이미지 자산만
남을 수 있습니다. 별도로 콘텐츠를 삭제하지 않습니다.

이번 변경에는 Studio 화면이나 스키마 변경이 없어 Studio 재배포가 필요 없습니다.
웹사이트 링크 변경은 PR 병합 후 사이트 배포에 반영됩니다.

## 언어별 콘텐츠 원칙

- 영어: 글로벌 독자가 이해할 제품 형태·맛·사용법·대체품을 설명합니다.
- 독일어: 독일에서 사용하는 재료 이름·구매처·대체품을 추가할 수 있습니다.
- Awin 가입은 완료 상태입니다. 광고주 프로그램 상태와 발급된 링크를 확인한 후
  기존 언어별 구매 링크 설정에 반영합니다. 독일용 링크를 영어 기본 링크로 쓰지 않습니다.
