# 떡볶이 검색 유입과 재료 안내 보강

이전에 받은 Search Console 자료에서 영어 떡볶이 페이지는 1,774회 노출, 2회 클릭, 평균 순위 54.3입니다.
자료의 마지막 날짜는 2026-09-29이며 이번 변경의 성과를 나타내지 않습니다.
떡볶이를 검색하는 독자가 재료를 고르고 조리할 때 필요한 내용을 보강합니다.

## 준비한 두 문서

- 떡볶이: English 소개·검색 제목·검색 설명. 기존 사진, Deutsch, 재료 분량, 시간, 인분, 연결된 4개 조리 단계 유지.
- 떡 재료(Tteokbokki-Tteok): English·Deutsch 소개·검색 제목·검색 설명. 기존 이름과 주소 유지. 빈 소개에 설명을 채움.

떡 재료 페이지는 이미 있지만, 레시피의 재료 이름 연결은 유용한 소개 또는 실제 사진이 있을 때만 표시됩니다.
이번 소개를 공개하고 웹사이트가 다시 빌드되면 기존 연결 로직으로 떡 이름을 눌러 재료 설명을 볼 수 있습니다.
사진이 없는 재료 페이지도 기존 텍스트 레이아웃으로 표시됩니다.
본문과 검색 문구 전체는 `tteokbokki-content-preview.ko.md`에서 읽을 수 있습니다.

## 실행·검토·공개

ZIP의 `apply-and-open-pr.sh`로 별도 작업 폴더와 검토용 PR을 준비합니다.
`prepare-tteokbokki-drafts.sh`로 로그인된 Sanity 사용자 권한으로 초안 두 개를 만듭니다.

1. https://hansik-young.sanity.studio/ 에서 Tteokbokki-Tteok 재료를 여세요.
2. English와 Deutsch 소개·SEO, 기존 이름·주소를 확인하고 Publish하세요.
3. 떡볶이 레시피의 English 소개·SEO와 기존 재료·조리 단계를 확인하고 Publish하세요.
4. 기존 공개용 웹훅의 빌드 완료 후 영어 떡볶이에서 떡 이름을 눌러보세요. 영어·독일어 재료 설명도 확인하세요.

자동 공개나 Studio 재배포는 하지 않습니다. PR 병합과 CMS Publish는 별도입니다.
초안에도 반응하는 웹훅이 따로 있으면 그 설정에 따라 빌드가 실행될 수 있습니다.

## 기존 편집 보호

소개가 준비 당시와 달라졌거나 다른 초안이 있으면 전체 작업을 중단합니다.
떡볶이 인분·시간·참조 목록과 연결된 재료 분량·조리 단계도 검사합니다.
마지막 확인 직후 다른 사용자의 공개 편집까지 잠글 수 없으므로 Publish 전 검토가 필요합니다.
동일한 준비 초안 또는 공개 내용은 건너뛰고 기존 초안을 덮어쓰지 않습니다.
