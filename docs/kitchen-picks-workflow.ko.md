# 재료·도구 선택 안내와 수익화 연결

기존 `/gallery` 주소를 유지하면서 EN Kitchen Picks / DE Zutaten & Küchenhelfer
페이지로 정리한다. 사진 추가 없이 기존 제품 4개와 주방 사진 5개를 활용한다.

## 방문자가 할 일

1. 기본 양념이나 주방 도구 안내에서 선택 기준을 확인한다.
2. 기존 사용 제품의 정확한 제품명과 변형을 확인한다. Jin Gold F3와 Jin S,
   Golden Curry Karakuchi와 다른 맵기 상품을 같은 제품이라고 소개하지 않는다.
3. 재료 안내나 실제 비빔 소스·카레 레시피로 이동한다.
4. 매장·구매 지역이 표시된 상품 링크를 열고 판매 페이지에서 구매 조건을 확인한다.

개인 사용 메모, 구매 링크, 주방 사진은 처음에 접혀 있다. 기존 메모·사진·상품
주소를 유지한다. 사진은 음식 전체를 볼 수 있게 contain으로 표시한다.
독일 매장 링크는 EN에서도 Germany로 표시한다. 미분류 매장은 배송 확인이
필요한 별도 그룹이다. 주소나 영어 제품명이 있다고 전 세계 배송이라고 추정하지 않는다.

## 승인된 링크가 생길 때

기존 재료 안내의 검토된 제품 중 정확한 URL로 승인·활성화된 제휴 링크만
별도 상품 옵션 영역에 모인다. 해당 영역은 개인 사용 후기와 구분한다.
개인 메모의 구매 링크도 기존 exact-URL resolver를 사용한다. 추적 주소로
변환되어도 원래 매장 이름과 구매 지역을 유지한다.

업체 신청 승인만으로 사이트가 바뀌지는 않는다. 발급된 실제 상품용 링크를
등록하고 별도 검토·활성화·배포해야 한다. iHerb처럼 기존 제품 목록에 없는
상품은 실제 상품과 국가별 배송을 확인한 뒤 별도 변경으로 추가한다.
현재 등록된 제휴 링크는 0개이며, 이번 변경은 새 링크를 만들거나 켜지 않는다.

## 수익화를 위한 검증 순서

| 단계 | 확인할 것                                            | 다음 행동                                  |
| ---- | ---------------------------------------------------- | ------------------------------------------ |
| 신청 | Asiafoodland·REWE·iHerb의 실제 승인 결과             | 승인 업체부터 제품 링크 준비               |
| 상품 | 제품명·용량·맵기·배송 지역과 연결되는 레시피         | 비교 가능한 제품을 적게 선정               |
| 연결 | 발급된 정확한 제품 링크, 일반/제휴 표시, 목적 페이지 | PR 미리보기 확인 후 활성화                 |
| 방문 | Search Console의 페이지·검색어별 클릭과 노출         | 이미 반응 있는 재료·레시피부터 보완        |
| 이동 | GA4 외부 링크 이벤트가 현재 실제 기록되는지 확인     | 기록될 경우 동의한 방문의 클릭만 해석      |
| 수익 | Awin 등 제휴 대시보드의 확정 수수료                  | 클릭만 많고 판매가 없는 상품의 적합성 검토 |

지금의 방문·구매 데이터가 제공되지 않았으므로 예상 수익이나 전환율을
추정하지 않는다. GA4 수치는 현재 분석 동의한 방문 기준이다. Pinterest
outbound clicks, Search Console 클릭, 제휴 클릭·확정 수수료는 서로 다른
수치이며 합산해 전체 방문자로 계산하지 않는다. 새 추적 스크립트는 추가하지 않는다.

다음 성과 확인에는 두 도메인의 Search Console 최근 28일 페이지·검색어
결과, 동의 기반 GA4의 방문·외부 링크 이벤트 상태, 제휴 승인 결과를 사용한다.
첫 달 목표는 사이트에 실제 제휴 상품 경로를 만들고 반응을 확인하는 것이며,
확정 수수료가 생기기 전에 수익이 발생했다고 기록하지 않는다.

## 적용

홈 메뉴를 늘리지 않고 기존 재료 목록·재료 상세·레시피의 갤러리 연결 문구를
페이지 역할에 맞게 바꾼다. canonical과 hreflang, 사이트맵의 `/gallery`는 유지한다.
기존 live SEO 검사도 새 제목에 맞게 갱신한다.

전체 빌드, 실제 EN/DE 링크·사진·메모·지역 표시, 미승인 링크 비노출,
승인 후 개별 광고 표시를 확인한다. PR Preview에서 모바일 접기/펼치기와
버튼 줄맞춤을 확인한 뒤 merge한다. Studio 배포나 Publish는 필요 없다.
