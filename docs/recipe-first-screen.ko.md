# 레시피 첫 화면 안내

레시피 제목과 작성자 아래에 기존 `seoDescription`의 짧은 소개를 표시합니다. 사진을 보기 전에 음식의 특징과 어떤 레시피인지 알 수 있도록 합니다. 영어·독일어는 각 언어에 이미 저장된 설명을 사용하며, 설명이 비어 있으면 소개 문단을 표시하지 않습니다.

기존 재료·조리 순서 이동 링크를 사진 위로 옮겼습니다. 모바일과 데스크톱 모두 두 링크를 표시하며, 같은 폭과 최소 44px 높이를 사용합니다. 기존 체크리스트와 조리 순서 위치로 이동하며 키보드 포커스를 표시합니다.

긴 레시피 메모, 재료 분량, 조리 단계, 사진, 검색용 정보와 구매 링크는 그대로 유지합니다. 방문자가 빨리 이해하고 요리를 시작하도록 돕는 화면 수정입니다. 검색 순위, 광고 승인 또는 수익 상승을 보장하지 않습니다.

## 미리보기 확인

영어와 독일어의 비빔 소스·불고기 등 레시피를 모바일과 데스크톱에서 확인합니다.

1. 제목 아래에 해당 음식의 짧은 소개가 보이는지 확인합니다.
2. 사진 위의 재료·조리 순서 버튼을 눌러 해당 구역으로 이동하는지 확인합니다.
3. 버튼 두 개의 폭이 같고 독일어 문구가 잘 보이는지 확인합니다.
4. 조리 모드, 체크리스트와 기존 구매 링크를 사용할 수 있는지 확인합니다.

Sanity 문서 수정, Studio 배포나 Publish는 필요 없습니다. 기존 검색 설명을 수정하면 다음 사이트 빌드에서 첫 소개에도 반영됩니다.
