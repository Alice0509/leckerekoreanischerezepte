# 레시피에서 다음 요리로 연결

기존 같은 분류 추천을 유지하면서, 실제 조리에 도움이 되는 연결을 앞에 배치한다. 새 레시피나 광고 링크를 추가하지 않고 기존 공개 레시피로 이어지는 길을 만든다.

| 현재 레시피  | 먼저 추천할 기존 레시피 | 이유                                 |
| ------------ | ----------------------- | ------------------------------------ |
| 비빔 면 소스 | 국수 삶기, 초고추장     | 면 준비 또는 다른 고추장 소스 탐색   |
| 국수 삶기    | 비빔 면 소스            | 삶은 면에 섞을 소스                  |
| 미역국       | 밥 짓기, 계란찜         | 국과 함께 차릴 밥·반찬               |
| 초고추장     | 김치전, 비빔 면 소스    | 찍어 먹을 요리 또는 다른 고추장 활용 |
| 김치전       | 초고추장                | 곁들일 딥                            |
| 일본 카레    | 밥 짓기                 | 카레에 곁들일 밥                     |

연결은 문서 ID로 찾고, 주소·사진·제목·분류는 해당 언어의 공개 catalog에서 가져온다. 각 추천 카드에는 추천된 요리 자체의 분류를 표시한다. 다른 분류의 요리도 포함하므로 영역 제목은 영어 `What to cook next`, 독일어 `Was du als Nächstes kochen kannst`로 바꾼다.

각 카드의 영어·독일어 짧은 설명은 조합을 제안하는 문구다. 운영자가 모든 조합을 직접 시험했다는 경험담을 만들지 않는다. 일본 카레를 한국 전통 요리로 소개하지 않는다.

추천할 대상이 현재 공개 catalog에 없으면 표시하지 않는다. 초안과 중복 문서는 제외한다. 최대 3개 카드, 기존 모바일 가로 스크롤, 같은 언어 링크를 유지한다. 분류 추천의 나머지 순서는 그대로 둔다.

검증: 기존 freshness 검사, 여러 대상의 순서·누락·초안·중복·번역 주소 검사, ESLint, Prettier, 전체 production build 및 생성 HTML의 실제 추천 카드와 분류·설명·주소 확인.

사이트 코드 PR을 Merge하면 Vercel 배포로 반영된다. Sanity 문서 수정, Studio deploy, 수동 Publish는 필요 없다. 새 추적이나 쿠키를 추가하지 않는다. 방문·구매·수익 증가를 보장하는 기능이 아니라 독자가 다음에 볼 요리를 고르기 쉽게 만드는 수정이다.
