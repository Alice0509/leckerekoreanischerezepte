# 육개장 검색 방문자를 위한 안내

영어·독일어 육개장 페이지에 기존 레시피 내용을 바탕으로 소개와 준비 안내를 추가합니다. 기존 재료·분량·조리 단계·타이머는 그대로 사용합니다.

- 당면은 기존 작성자 메모대로 약 1시간 불린 뒤 별도로 약 4분 삶습니다. 표시된 50분 레시피 시간 외에 미리 불리는 시간을 계획하도록 안내합니다.
- 질문 세 개는 처음에 접혀 있습니다. 당면, 진간장·국간장, 고춧가루 설명을 읽고 실제 재료 페이지로 이동할 수 있습니다.
- 이미 있는 구매 안내와 일반 재료 설명을 구분하기 위해 기본 설명의 제목을 `Ingredient tips / Hinweise zu den Zutaten`로 바꿉니다.
- Sanity 데이터 수정, Studio 배포나 Publish는 필요 없습니다. 사이트 PR을 merge하면 Vercel 배포에 반영됩니다.

## 미리보기 확인

1. 영어·독일어 `/recipes/yukgaejang`를 모바일에서 엽니다.
2. 준비 안내가 보이고 추가 질문은 접혀 있는지 확인합니다.
3. 질문을 열고 네 개의 재료 링크가 해당 언어의 설명 페이지로 이동하는지 확인합니다.
4. 재료 분량, 아홉 개 조리 단계와 기존 타이머가 그대로인지 확인합니다.
5. 소보로빵·단팥빵 등 다른 레시피에는 육개장 안내가 나오지 않는지 확인합니다.

## 성과 확인

배포일을 기록해 두고 Search Console에서 같은 길이의 기간을 비교합니다. 독일어 육개장 페이지의 노출·클릭·CTR·검색어를 함께 보고, 계절이나 검색 순위 변화도 고려합니다. 수익은 제휴 승인과 실제 판매가 확인된 뒤 별도로 평가합니다.
