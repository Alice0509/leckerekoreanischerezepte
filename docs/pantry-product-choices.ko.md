# 해외 독자를 위한 제품 선택 안내

참기름·진간장·고춧가루의 페이지 요약, 활용, 제품 선택, 대체·보관 FAQ를 재료에 맞게 구성한다. 특히 영어 참기름·고춧가루의 일반 재료 안내를 구체적인 설명으로 바꾼다. 기존 Sanity 본문과 사진은 그대로 보여준다.

- 참기름: roasted/toasted 표시, 순수 참기름과 혼합유 구분, 들기름·드레싱과 구분.
- 진간장: Jin Ganjang/진간장 표시, Jin S와 Jin Gold 제품군 구분, 국간장의 염도 차이와 양념 간장 구분.
- 고춧가루: 굵은 것과 고운 것, 고추장과의 차이, 원산지·맵기·원재료 별도 확인.

영어 구매 안내는 전 세계 독자가 자국의 매장을 찾도록 한다. 검증한 미국 상품은 United States 영역에만 표시한다. 독일어 구매 안내는 독일 기준이다. 진간장의 검증한 미국 상품 링크는 이번에 확보하지 못했으므로 빈 미국 구매 영역을 만들지 않는다.

정확한 상품 주소 세 개를 추가한다. 가격과 재고는 고정해 표시하지 않는다.

| 재료 | 시장 | 상품 | 판매 페이지 |

| 참기름 | 독일 | Ottogi geröstetes Sesamöl 160 ml | [Asiafoodland](https://www.asiafoodland.de/food/oel-essig-fischsauce/oele-fette/ottogi-koreanisches-sesamoel-100-pur-160-ml.html) |
| 참기름 | 미국 | Otoki Premium Roasted Sesame Oil 10.82 fl oz | [Weee!](https://www.weee.com/en/product/Otoki-Premium-Roasted-Sesame-Oil/85092) |
| 진간장 | 독일 | Sempio Jin S 860 ml | [Handokmall](https://handokmall.de/de/sempio-sojasauce-jin-s-860ml/12394) |

상품 예시를 개인의 실제 사용 경험이라고 표현하지 않는다. 새 진간장 상품은 Jin S이며 Jin Gold와 같은 제품이라고 하지 않는다. 상품 이름·포장·배송 지역·원재료는 구매 전 판매 페이지에서 확인한다. 기존 제휴 resolver를 사용하며 승인·활성화되지 않은 링크는 일반 상품 링크다.

## 검증

실제 페이지 렌더링 테스트에서 두 언어의 본문·FAQ 일치와 기존 구매 링크를 확인한다. 상품 안내 테스트는 정확한 제품 주소, 지역 분리, 미승인 제휴 비활성화, 빈 미국 진간장 영역 제외를 확인한다. production 공개 내용 기반 280페이지 빌드가 성공했다. 생성 HTML에서도 관련 재료 6페이지의 FAQ와 새 상품 주소를 확인했다. 브라우저 모바일 검토는 PR Preview에서 진행한다.
