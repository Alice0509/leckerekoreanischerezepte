# 구매처 클릭 측정 확인

현재 사이트에 GA4 코드가 있으며 분석 쿠키에 동의한 방문자에게만 로드됩니다. 이번 변경은 GA4 계정 설정을 수정하거나 새 추적 코드를 설치하지 않습니다.

## 설정 확인

1. Google Analytics에서 이 사이트에 사용하는 속성을 선택합니다.
2. 관리(Admin) → 데이터 수집 및 수정(Data collection and modification) → 데이터 스트림(Data streams) → 해당 웹 스트림으로 이동합니다. 화면 언어에 따라 항목 이름은 다를 수 있습니다.
3. 향상된 측정(Enhanced measurement) 설정에서 외부 클릭(Outbound clicks)이 켜져 있는지 확인합니다. 이미 켜져 있으면 다시 설정할 필요가 없습니다.
4. 분석에 동의한 브라우저에서 고추장이나 고춧가루 구매 링크를 한 번 클릭합니다. 본인 시험 클릭은 운영 성과에 포함하지 않습니다.
5. 실시간/디버그 또는 이후 보고서에서 `click` 이벤트와 `link_domain`, `link_url`, `outbound` 값을 확인합니다. 실시간에 항상 즉시 모든 매개변수가 보이는 것은 아닙니다.

영어·독일어 사이트가 서로 다른 속성이나 스트림을 사용한다면 각각 확인합니다. 탐색에서는 `Event name = click`으로 제한하고 구매처의 `Link domain` 또는 `Link URL`을 선택해 일반 외부 링크 클릭과 구분합니다.

외부 클릭 자동 수집이 켜져 있으면 페이지 코드 수정은 필요 없습니다. 교차 도메인 측정 대상으로 등록한 도메인은 외부 클릭에서 제외될 수 있습니다.

## 2주마다 확인할 것

| 지표 | 확인 위치 | 의미 |
| --- | --- | --- |
| 검색 클릭·검색어·유입 페이지 | Search Console | 검색에서 사람들이 무엇을 찾았는지 |
| 제품별 구매처 클릭 | GA4 탐색: Link URL, Link domain, Event count | 어떤 제품에 구매 관심이 있는지 |
| 유입 페이지·사이트 구분 | GA4: Page path, Hostname 등 | 영어·독일어 사이트 및 가이드별 비교 |
| 주문과 확정 수수료 | 승인 후 Awin 또는 해당 제휴 플랫폼 | 실제로 수익이 인정됐는지 |

GA4의 동의 기반 수치, Search Console의 검색 클릭, 제휴 플랫폼의 클릭·주문은 수집 범위가 달라 서로 같지 않습니다. 클릭을 판매나 수익으로 계산하지 않습니다. GA4에서 정보가 수집되는지 확인하기 전에는 0건을 실제 방문자 관심이 없다는 뜻으로 해석하지 않습니다.

공식 안내: https://support.google.com/analytics/answer/13566436?hl=en
